●Method of Starting the Game
　Please start "Game.exe" located within the main file.

●Control Method
　Decide/Examine: Left Click
　Menu/Cancel: Right Click
　Auto Message Playback: A key
　Fast Message Playback: Ctrl key

●Game Progression
　Move by clicking the arrow icons or other icons displayed on the screen.
　Clicking on the characters present will start a conversation.
　Once all events where you can talk to the characters that can be spoken to are completed, the event will progress.

●About the Gallery
　After the game ends, a gallery will be added to the title screen.
　Here, all H-scenes are viewable.
